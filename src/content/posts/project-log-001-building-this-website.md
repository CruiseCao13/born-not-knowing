## Goal

Build a quiet personal website that makes it easier to write, review, and organize learning notes over time.

## Why I am building it

I do not want another place that rewards pretending to be finished. I want a durable archive for engineering, English, markets, music, projects, and reflection.

## Tech stack

This site uses Astro, TypeScript, Markdown / MDX, AstroPaper, static site generation, RSS, sitemap, Pagefind search, and dark mode.

## What I customized

I changed the site identity, homepage, navigation, footer, content categories, core pages, and starter posts. The design stays text-first because publishing should be easier than redesigning.

## What is still rough

The first version uses starter content and simple project cards. The next improvement is not more decoration. It is better notes.

## Next steps

Publish weekly learning notes, review the Now page monthly, and add markets study notes with clear disclaimers and review dates.
